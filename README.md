# Trabajo Programación en Entorno Servidor

Trabajo final de trimestre de Programación en Entorno Servidor sobre una aplicacion para gestionar el periodo de empresas de los alumnos el cual los maestro puedan utilizarla

## Base de datos

Se utilizara la base de datos relacional MySQL para el guardado de datos

## IDE y Tecnologías

Se utilizara Visual Studio Code para las Vistas y para el modelo y el controlador se utilizara Eclipse
para SpringBoot, ya que es el framework que se va a utilizar.

Se utilizara JDK 17 y Maven

Se ha instalado las dependecias:

-Thymeleaf<br>
-Spring Web<br>
-MySQLDriver<br>
-Spring Boot DevTool<br>
-Spring Data JPA<br>
-Spring Security<br>
